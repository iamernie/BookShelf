## Reading Goals

Set and track reading goals to stay motivated.

### Creating a Reading Goal

1. Navigate to **Stats** → **Goals**
2. Click **"Create Reading Goal"**
3. Choose goal type
4. Set target and timeframe
5. Save goal

### Goal Types

BookShelf supports 6 types of reading challenges:

#### 1. Total Books Goal

Read X books in a year.

**Settings:**
- Target: Number of books
- Year: Which year (e.g., 2026)

**Progress:**
- Books counted when status changes to "Read"
- Completion date must be within goal year
- Re-reads can be counted (optional setting)

**Example:** Read 52 books in 2026 (one per week)

#### 2. Genre Challenge

Read X books from specific genres.

**Settings:**
- Target: Number of books
- Genres: Select one or more genres
- Timeframe: Start and end date

**Progress:**
- Only books with selected genres count
- Books with multiple genres count once

**Example:** Read 12 fantasy books in 2026

#### 3. Author Challenge

Read X books by different authors OR X books by a specific author.

**Settings:**
- Target: Number of books/authors
- Mode: Different authors OR specific author
- Author (if specific): Choose from your library
- Timeframe: Start and end date

**Progress:**
- Different authors mode: Each author counts once
- Specific author mode: All books by that author

**Examples:**
- Read 25 different authors in 2026
- Read 10 books by Brandon Sanderson

#### 4. Format Challenge

Read X books in specific formats.

**Settings:**
- Target: Number of books
- Formats: Select formats (Ebook, Audiobook, Paperback, Hardcover)
- Timeframe: Start and end date

**Progress:**
- Only books with selected formats count

**Example:** Listen to 24 audiobooks in 2026

#### 5. Page Count Goal

Read X pages total.

**Settings:**
- Target: Total pages
- Timeframe: Start and end date

**Progress:**
- Page counts summed from all books read
- Only books with page counts included

**Example:** Read 15,000 pages in 2026

#### 6. Monthly Challenge

Read X books every month.

**Settings:**
- Target: Books per month
- Year: Which year

**Progress:**
- Separate counter for each month
- Must complete book within the month

**Example:** Read 4 books every month in 2026

### Managing Goals

**View Progress:**
- Dashboard shows active goals
- Stats page shows detailed breakdown
- Progress bars and percentages

**Edit Goal:**
- Click goal card → **Edit**
- Change target or dates
- Save changes

**Complete Goal:**
- Mark as complete when achieved
- Celebrate! 🎉
- Goal moves to completed list

**Delete Goal:**
- Remove goals you no longer want to track
- Historical data preserved

### Goal Insights

**On Track:**
- Green indicator when ahead of pace
- Shows books/days ahead

**Behind Pace:**
- Yellow indicator when slightly behind
- Shows books/days needed to catch up

**At Risk:**
- Red indicator when significantly behind
- Suggested pace to complete

## DNF Tracking

Track books you didn't finish:

### Marking a Book DNF

1. Open book details
2. Change status to **"DNF"**
3. Optionally provide:
   - Page number stopped
   - Percentage read
   - Reason (not engaging, too difficult, etc.)
   - DNF date

### Why Track DNF?

**Benefits:**
- Honest reading log
- Identify patterns (genres you don't enjoy, writing styles)
- Future reference (avoid similar books)
- Realistic goal tracking

**Statistics:**
- DNF rate (% of started books)
- Common DNF reasons
- DNF by genre/author

### DNF Insights

View in Stats → **DNF Analysis**:

- Total DNF count
- DNF percentage
- Most common reasons
- Genres with highest DNF rate
- Authors with DNF books
- Average abandonment point (page/%)

## Tips for Better Tracking

### Consistent Data Entry

1. **Set reading dates** - Mark when you start/finish
2. **Rate promptly** - Rate while book is fresh
3. **Track DNFs honestly** - Don't force books
4. **Log re-reads** - Enable re-read counting if desired

### Goal Setting Strategies

**Be Realistic:**
- Start with achievable goals
- Consider your schedule
- Account for reading speed

**Diversify:**
- Mix goal types (total + genre + format)
- Challenge yourself with new genres
- Balance quantity and quality

**Adjust as Needed:**
- Edit goals if life changes
- No shame in lowering targets
- Focus on enjoyment, not just numbers

### Using Statistics

**Identify Patterns:**
- What genres do you rate highest?
- Which authors do you return to?
- When are your most productive reading months?

**Discover Preferences:**
- Physical vs digital vs audio
- Fiction vs non-fiction ratio
- Preferred book lengths

**Plan Future Reading:**
- Fill gaps in genre exploration
- Revisit favorite authors
- Try formats you don't usually choose

### Reading Challenges

**Create Personal Challenges:**
- Read alphabet (author last name A-Z)
- Read books you already own
- Read diverse authors
- Tackle TBR pile

**Join Community Challenges:**
- Goodreads Reading Challenge
- Genre-specific challenges
- Reading groups

**Track in BookShelf:**
- Use tags for challenge books
- Create Smart Collections
- Monitor progress in Stats

## Privacy

All statistics are private by default:

- Only visible to logged-in users
- Admin controls sharing settings
- Public widgets optional
- OPDS catalog configurable (private/public)

Enable public access in **Admin → Settings → Privacy**
